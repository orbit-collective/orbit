# Tłumaczenia (i18n)

Interfejs jest dostępny po angielsku (`en`) i polsku (`pl`). Teksty leżą w plikach tablic PHP Laravela i są czytane w Reakcie przez `laravel-react-i18n`; własne komunikaty serwera podążają za językiem wybranym przez użytkownika.

- [01 - Przetłumacz tekst i dodaj język](01-translate-a-text-and-add-a-language.md) - jak to działa, pierwsze kroki
- [02 - Dodaj pliki tłumaczeń](02-add-translation-files.md) - nazewnictwo plików, zasady kluczy, liczba mnoga, stałe, katalogi z serwera
- [03 - Dodaj nowy język](03-add-a-new-language.md) - pełna lista kroków
- [04 - Przełączniki języka](04-language-switchers.md) - menu w pasku bocznym, Preferencje, paleta poleceń
