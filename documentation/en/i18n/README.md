# Translations (i18n)

The UI is available in English (`en`) and Polish (`pl`). Texts live in Laravel PHP array files and are read in React through `laravel-react-i18n`; the server's own messages follow the language the user picked.

- [02 - Add translation files](02-add-translation-files.md) - file naming, key rules, plurals, constants, server catalogs
- [03 - Add a new language](03-add-a-new-language.md) - end-to-end checklist
- [04 - The language switchers](04-language-switchers.md) - sidebar menu, Preferences, command palette
